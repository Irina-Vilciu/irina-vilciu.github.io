# Irina Vilciu — Academic website

Static academic website for GitHub Pages. Pages: Overview, Research, Publications, Teaching, About, CV and Contact.

## Editing

Edit the relevant HTML page directly. Shared appearance is in `styles.css`; mobile navigation and publication filters are in `app.js`. No build step, tracking scripts or third-party font services are required.

The home page, publication catalogue and teaching page include selected overlapping references; update those copies together. The full catalogue includes 40 publications and teaching materials, plus one doctoral thesis. Project roles are taken from the supplied records.
